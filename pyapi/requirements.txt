# IMPORTANT:
# - "--extra-index-url" (not "--index-url") is used so pip searches
#   both PyPI and the PyTorch CPU index in the same run.
# - torch/torchaudio/torchvision are pinned with the "+cpu" suffix,
#   which only exists on the PyTorch CPU index. This forces pip to
#   select the CPU wheels deterministically and prevents it from
#   falling back to the CUDA build on PyPI.
# - The pinned versions (2.15.0 / 2.11.1 / 0.29.2) are RC-cycle
#   builds currently published on the PyTorch test channel.
#   If you later move to stable releases, switch the index below
#   to https://download.pytorch.org/whl/cpu and drop the +cpu pins
#   (or update to the matching stable versions).
# - Do NOT add a second "--index-url" line anywhere in this file:
#   it would reset the index for the entire install and cause the
#   CUDA torch wheel to be pulled in.
# ==========================================
